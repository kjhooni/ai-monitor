1. AI 활용 개요

■ 활용 AI 모델/도구
- Anthropic Claude (claude-sonnet-4-6) — 서버 장애 상황 분석 및 조치 판단에 활용

■ 활용 목적
기존에는 관제팀이 모니터링 알람을 확인하고, 담당자에게 연락하거나 간단한 장애를 직접 처리하는 방식으로 운영되었습니다.
이 과정에서 발생하는 야간/주말 대응 지연, 단순 반복 업무 부하, 담당자 판단 의존을 줄이기 위해,
Claude AI를 활용한 자동 장애 분석 및 대응 시스템을 구축하였습니다.

■ 전체 흐름

[수집]
Prometheus + node_exporter
각 서버의 CPU / 메모리 / 디스크 / SWAP 메트릭 60초 주기 수집
        ↓
[임계값 초과 감지]
설정된 임계값 초과 시 SSH로 서버에 직접 접속하여
프로세스 현황, 디스크 사용 상세 등 진단 데이터 수집
        ↓
[AI 분석 - Claude]
수집된 메트릭 + 진단 데이터 + 과거 장애 이력을 Claude에 전달
→ 단순 임계값 초과인지 실제 장애인지 판단
→ 원인 프로세스 또는 원인 특정
→ 심각도(low / medium / high / critical) 결정
→ 권장 조치 및 자동 실행 가능한 bash 명령어 생성
        ↓
[알림]
Microsoft Teams Adaptive Card로 담당자에게 전송
→ 분석 결과 / 권장 조치 / TOP 프로세스 현황 포함
→ 담당자 멘션으로 즉시 인지 가능
        ↓
[조치 확인 및 실행]
Claude가 자동조치 가능하다고 판단한 경우
→ Teams 카드 내 "자동조치 실행" 버튼 제공
→ 담당자가 확인 페이지에서 명령어 설명 검토 후 실행 승인
→ SSH를 통해 대상 서버에 명령어 자동 실행
→ 실행 결과(stdout) 포함하여 Teams로 결과 통보
